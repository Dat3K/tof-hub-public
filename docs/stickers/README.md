The local source catalog is `apps/web/public/game-data/en/runtime/cosmetics.json`,
category `chatStickers`. These items retain their original GIF frames, dimensions,
looping and timing. The case study only sets the displayed size to 56 × 56, inline with the related paragraph.

The catalog records material-based reconstruction with `timing: inferred`.
See [cosmetics source documentation](../game-data/cosmetics.md) for the raw
`DT_BigEmoji` / `DT_ChatHugeEmoji` tables, material references, atlas parameters
and the reconstruction's limits. The game artwork belongs to its respective
owners; these are existing game assets, not newly generated illustrations.
