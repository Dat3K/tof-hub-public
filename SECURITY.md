# Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/smilekritik/tof-hub-public/security/advisories/new)
for security issues. Include the affected version or commit, steps to reproduce
and the impact you observed. Reports are visible to the maintainer through GitHub.

For ordinary bugs, incorrect game data and questions, use the
[issue forms](https://github.com/smilekritik/tof-hub-public/issues/new/choose).
